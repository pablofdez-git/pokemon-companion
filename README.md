# Pokémon Companion

Captura Pokémon mientras programas.

- Cada vez que guardas un archivo con cambios, ganas monedas 🪙.
- A veces aparece un Pokémon salvaje: lánzale una Pokéball para intentar capturarlo.
- Compra más balls en la tienda (pulsa las monedas de la barra de estado).
- Mira tus balls y tus Pokémon en la mochila de la barra lateral.
- Captura Pokémon distintos para desbloquear nuevas generaciones.

Proyecto personal. Los Pokémon y sus imágenes pertenecen a Nintendo, Game Freak y The Pokémon Company. Los datos vienen de la PokéAPI.
